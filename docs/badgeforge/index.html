What it adds

Custom badges

Add your own cosmetic labels to your profile badge row.

Showcase date

Set a fictional account creation date for your local profile display.

Game activity

Show custom game names and mock playtime as profile cosmetics.

Your settings

Change the values from BadgeForge's plugin settings whenever you want.

Installation

1

Open Revenge settings.
Go to the plugin repository / manager section.

2

Add the repository.
Copy this repository URL:
https://raw.githubusercontent.com/tiktoknotificationtroll-wq/Revenge-plugin/gh-pages

3

Install BadgeForge.
Refresh the repository, find BadgeForge and install it. Enable the plugin if prompted.

4

Make it yours.
Open BadgeForge's settings and edit your badges, date and game showcase.

Important: BadgeForge is a local cosmetic showcase. It does not grant official Discord badges, change Discord account data or make these mock details visible to other users. Actual display depends on compatibility with your installed Revenge build.
