BadgeForge

Custom profile badges and a personal showcase for Revenge. Add your own badge labels, set a profile join date, and display custom game activity.

https://raw.githubusercontent.com/tiktoknotificationtroll-wq/Revenge-plugin/gh-pages/index.json

To install this plugin, copy the URL above into the Plugins page in Revenge. Tap the URL to copy it.

BadgeForge is cosmetic and local to your client. It does not grant official Discord badges or change Discord's server-side account data.
